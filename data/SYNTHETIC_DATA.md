# Synthetic optical input

`synthetic_epsilon.csv` is generated by `generate_synthetic_epsilon.py` from a
single damped Lorentz oscillator. It is an explicitly synthetic, passive input
for code examples and numerical checks. It is **not** measured CFO data, a DFT
result, a fit to an experiment, or a material recommendation.

The convention is exp(-i omega t), with epsilon = epsilon1 + i epsilon2 and
epsilon2 >= 0. The table covers 200–800 nm in 10 nm increments and stores the
corresponding principal refractive-index branch as `n` and `k`.
